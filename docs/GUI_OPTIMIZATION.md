# DAE-ELM GUI 优化方案

## 当前问题分析

### 1. 布局问题

| 问题 | 描述 | 严重程度 |
|------|------|----------|
| 视觉层次不清晰 | 各tab内容垂直堆叠，无主次之分 | 高 |
| Overview标签页内容空洞 | 仅4个大按钮+项目信息，缺乏Dashboard功能 | 高 |
| 配置与执行分离 | 需要切换多个tab才能完成"配置→执行→查看结果"的流程 | 中 |
| 进度反馈不突出 | ProgressBar默认隐藏，优化过程缺乏实时状态可视化 | 中 |
| 响应式布局缺失 | 固定窗口大小(1200x800)，不适应不同屏幕 | 低 |

### 2. 视觉设计问题

| 问题 | 描述 | 严重程度 |
|------|------|----------|
| 字体无特色 | 使用系统默认字体(sans-serif)，缺乏品牌识别度 | 中 |
| 色彩体系混乱 | 硬编码颜色值(如`#0078d4`, `#107c10`)，无统一调色板 | 高 |
| 样式代码内联 | 大量`setStyleSheet()`散落各处，无QSS统一管理 | 高 |
| 缺乏深度层次 | 无阴影、渐变、纹理等视觉层次感 | 中 |
| 暗色模式缺失 | 仅支持亮色主题，不适合长时间使用 | 中 |
| 图表样式陈旧 | Matplotlib默认样式，无品牌定制 | 中 |

### 3. 交互体验问题

| 问题 | 描述 | 严重程度 |
|------|------|----------|
| 数据导入反馈不足 | 导入后无数据预览/统计信息展示 | 高 |
| 优化过程无实时图表 | 只能看日志，无法实时观察收敛曲线 | 高 |
| 日志功能简陋 | QTextEdit纯文本，无等级着色/过滤/搜索 | 中 |
| 快捷键缺失 | 无键盘导航，无法高效操作 | 低 |
| 空状态无引导 | 各模块在无数据时仅显示"暂无数据" | 中 |

### 4. 功能缺失

| 问题 | 描述 | 严重程度 |
|------|------|----------|
| 数据预览缺失 | 导入CSV/Excel后无法快速查看数据分布 | 高 |
| 图表导出缺失 | 可视化结果无法导出为PNG/SVG | 中 |
| 配置保存/加载 | 无法保存项目配置供后续使用 | 中 |
| 实时收敛监控 | 优化过程无法实时显示适应度变化 | 高 |
| 帮助文档入口深 | 用户手册需要通过菜单→帮助→用户手册访问 | 低 |

---

## 优化目标

基于frontend-design skill的设计原则，为DAE-ELM打造**工业科技风格(Industrial Tech)**界面：

1. **视觉识别度**: 深色主调 + 科技蓝/青绿点缀，传达专业与智能
2. **信息密度优化**: 在保持清晰度的前提下，提高数据展示效率
3. **操作效率提升**: 减少操作步骤，支持快捷键操作
4. **实时反馈强化**: 优化过程全程可视化，增强用户信心

## 实施计划

### Phase 1: 样式系统重构 (1-2天)

1. 创建`config/styles.qss`，定义完整的色彩、字体、组件样式
2. 修改`main_window.py`，移除硬编码样式，改用QSS类名
3. 创建自定义QSS样式表加载器，支持亮/暗主题切换
4. 为所有组件添加语义化ObjectName

### Phase 2: 布局重构 (2-3天)

1. 将TabWidget导航改为左侧Drawer导航
2. 重构Dashboard为信息卡片式布局
3. 添加实时状态概览组件
4. 优化ConfigWidget的分组与布局

### Phase 3: 可视化增强 (2-3天)

1. 实时收敛曲线绘制
2. 数据导入后的统计信息展示
3. 图表导出功能
4. Matplotlib样式定制(与整体主题协调)

### Phase 4: 交互优化 (1-2天)

1. 快捷键支持
2. 日志系统增强(着色、过滤)
3. 空状态引导提示
4. 进度反馈优化

### 优先级排序

```
P0 (必须修复):
- styles.qss缺失导致的样式加载警告
- 优化过程无实时可视化

P1 (重要优化):
- Dashboard信息卡片化
- 配色系统统一
- 数据导入反馈增强

P2 (体验提升):
- 快捷键支持
- 日志增强
- 暗色主题
```
